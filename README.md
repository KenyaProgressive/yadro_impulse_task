# yadro_impulse_task
Тестовое задание на стажировку YADRO (Генерация артефактов на основе данных о UML диаграммах)


## Инструкция 

1. Склонируйте репозиторий
   > git clone ...
   > 
   > cd src
2. Установите и активируйте виртуальное окружение
   > python -m venv .venv
   > .venv/Scripts/activate (для Windows)

3. Запустите программу
   > python main.py
